**Mathematical/architectural points**

1. Use induced subtype as the canonical residual everywhere. `deleteIncidenceSet` is a counting helper for the singleton formula, not a second residual API. Its tau transport is proved by observing its isolated vertex cannot occur in an injective square, then restricting/lifting square maps.
2. `erase_edgeCount` deliberately uses addition. The informal expression `m - ∑degree + internal` is false as a natural-number formula with truncated subtraction when the degree sum exceeds `m`; the addition identity is exact.
3. Attachment pairs count edges once because the first endpoint lies outside D and the second inside D. Endpoints need not be distinct between different attachments.
4. A global strong induction on m works with the contracts above. Unsupported edge first; then any global degree ≥4; otherwise select an edge-containing component. Its degrees are 2 or 3. Apply mixed/local-cubic reductions to the **original graph**, or remove a whole C4 component using `square_component_reduction`. This avoids illegally invoking IH on a component with the same m and isolates outside it.
5. The cubic hypothesis is deliberately local to the four square vertices. An “all vertices cubic” contract prevents application to a cubic component in a graph with other components.
6. For the cut lemma, use a shortest connected path to find a first attachment. Its supporting square must cross the component boundary again. Residual edges cannot leave a residual component. This is simpler than constructing `Walk.IsCycle`, although a bridge API is available.
7. `square_supported_no_bridge` itself is easy directly: the other three square edges give a walk between endpoints after deleting the given edge. `SimpleGraph.isBridge_iff` then applies.
8. The chorded reduction requires an explicit combinatorial argument that every square meeting `{a,b,c}` contains b. After excluding b, a and c have only each other and d as possible neighbours; injectivity of a square rules it out. Do not cite generic triangle articulation facts unless separately proved.

The symbolic extension proof needs no maximum-degree hypothesis. Pull back labels \(A_0,A_1,A_2,B_0,B_1,B_2\) through the residual isomorphism, with missing edge \(A_0B_0\). Degree four forces neighbor split \(3+1\), \(2+2\), or \(1+3\).

- For \(3+1\), delete two A vertices. The surviving A vertex and z have at most one common B neighbor, ruling out a square. Exchange parts for \(1+3\).
- For \(2+2\) with \(zB_0\), delete \(A_1,A_2\). Again A₀ and z have at most one common B neighbor. If \(zA_0\), exchange parts.
- Otherwise delete \(A_1,B_1\). The remaining edges are \(A_0B_2,A_2B_0,A_2B_2,zA_2,zB_2\): a triangle with two leaves, hence square-free.

This is symbolic case analysis on neighbor counts and distinguished vertices. It must not become an exhaustive decision procedure over extension graphs.

For the cubic lemma, count crossings of an arbitrary square between the two sides. The count is even. Four crossings are impossible because cross edges form a matching, whereas four crossings require two incident cross edges at every square vertex. A mixed square therefore has precisely two crossings and one internal edge on each side. An internal edge of the left C₄ avoiding \(l(0)\) contains \(l(2)\); its crossing at that endpoint contains \(r(\mu(2))\). The stated two-vertex transversal follows.

Explicit reconstruction maps:

- Degree-four vertex z over a residual C₄: wheel labels 0–3 follow the inverse residual isomorphism; label 4 maps to z.
- z over residual W₅: the residual hub already has degree four, so z joins exactly its four rim vertices. Octahedron labels map to
  \[
  (z,\text{hub},\text{rim}_0,\text{rim}_2,\text{rim}_1,\text{rim}_3).

- Mixed case with residual cycle \(a,t,b,s,a\): map K₃,₃−e labels
  \[

Proof organization:

1. **Small graphs, A-owned:** use finite certificates for upper/lower transversal bounds, then `tau4_eq_of_certificates`; obtain the lower bound by applying `hlower` to an attained minimum. Never attempt `decide` on `tau4` itself. Prescribed optimal sets are the explicit sets in the informal proof. `prescribedOptimal_iso` maps a chosen transversal back along `e.symm`, using injectivity for cardinality and square transport for coverage. This is a necessary handoff: classification alone does not give the required transversal through attachment vertices.
2. **Star, B-owned:** first turn “no `HasMatching2`” into pairwise edge intersection using the four endpoint function `![a,b,c,d]`. If there is no edge, return `G = ⊥`. Otherwise choose `xy`. If all edges meet `x`, finish; otherwise choose `yz` after orienting an edge missing `x`. If every edge meets `y`, finish; otherwise an edge missing `y` must meet both `xy` and `yz`, hence is `xz`, contradicting `htri`. This formulation correctly covers an empty vertex type.
3. **K₃,₃−e arrows:** if red contains a 2-matching, finish. Otherwise apply `star_or_empty` to the red graph; triangle-freeness descends through `R ≤ k33MinusEdge`. In the star branch use `k33_square_avoids_vertex` at its center; each witness edge is nonred because neither endpoint is the center. In the empty branch use the witness avoiding vertex `0`. No exhaustive enumeration of red graphs is needed.
4. **Gluing:** for arbitrary `R ≤ F17`, set `R₀ := R.comap leftCopy`, `R₁ := R.comap rightCopy`. The two adjacency equivalences prove each is below `k33MinusEdge`. Apply its arrowing theorem twice. A blue square in either pulled-back coloring maps to a blue square in `F17 \ R` by `hasC4_map` and `sdiff_adj`. Otherwise concatenate the two red 2-matchings with `matching2_union`. The bridge is used only for connectedness.
5. **Coloring:** from each of the four red matching edges choose its endpoint in `S`; the matching’s endpoint injectivity makes these four choices distinct. Apply finite cardinality monotonicity. A blue square of `F \ incidentRed F S` cannot contain any vertex of `S`, contradicting the transversal property.

### A6. Five reductions and A

Each contract in §1 records the actual residual and exact count where needed.

- **Degree at least four:** use `D = X = {v}` and singleton counting.
- **Mixed degrees:** delete \(v\), after which \(u\) has degree one; remove \(u\) without changing the residual transversal number. Exactly \(2+3-1=4\) edges disappear. No attachment-distinctness assumption belongs here.
- **Two-regular component:** choose a supported square. Its vertices already have both neighbours inside the square. Connectedness forces it to contain every vertex. Build the isomorphism.
- **Cubic chordless square:** use `D = univ.image f`, `X = {f 0,f 2}`. Any square avoiding \(X\) cannot contain `f 1` or `f 3`, which each have at most one surviving neighbour. The induced square has four edges, giving \(12-4=8\) removed edges.
- **Subcubic chorded square:** with chord `f 0–f 2`, use `D = {f 0,f 1,f 2}`, `X = {f 1}`. The diagonal endpoints already have three neighbours in the four-vertex configuration. After avoiding `f 1`, they cannot participate in an injective square. The three deleted vertices induce a triangle, so the exact loss is `G.degree (f 1) + 3 ≥ 5`.

The chorded reduction is **not valid at maximum degree four**. Its subcubic hypothesis must survive every application.

For `degree_two_three_cases`, a path joining the two degree classes must contain an adjacent mixed pair. A general classification of regular graphs is unnecessary.

For A, strongly induct on edge count, universally quantifying the finite vertex type at a fixed universe:

1. Zero edges give no square and hence \(\tau_4=0\).
2. Delete an unsupported edge if one exists.
3. Otherwise remove a vertex of degree at least four if one exists.
4. Otherwise choose a component containing an edge. Its degrees lie in `{2,3}`.
5. Apply the mixed reduction to the original graph; or choose a square in the cubic component and apply the local square reduction to the original graph; or remove the whole two-regular \(C_4\) component with `square_component_reduction`.

The cubic reduction deliberately assumes degree three only at its four vertices. A globally cubic hypothesis would prevent its use inside a disconnected graph.

**Do not apply the induction hypothesis merely because a component is proper.** A component may contain all edges of \(G\), with isolates elsewhere. Removing the whole \(C_4\) component or applying a local reduction gives the required strict edge decrease.

### B7. Cubic crossing and contradiction

**`Equality/Cubic.lean`:**

```lean

    {V : Type u} (G : SimpleGraph V)

      G.Adj (l i) (r j) ↔ μ i = j) :

theorem equality_cubic_impossible
    {V : Type u} [Fintype V] (G : SimpleGraph V)
    (hc : G.Connected)

    (hm : edgeCount G ≤ 16)
    (ht : Tight G)
    (ih : SmallerClassified G)
    (h3 : ∀ v, G.degree v = 3) :
    False := by
  sorry
```

For the crossing lemma, assign each vertex of an arbitrary square to its unique side. The number of side changes around a closed four-cycle is even. A mixed square has at least one change. Four changes would give two incident crossing edges at every square vertex, contrary to the matching relation. Thus there are exactly two changes.

The two crossing edges cannot be consecutive, again because the crossing graph is a matching. Consequently there is one internal edge on each side. If the left internal edge avoids `l 0`, it contains `l 2`; its crossing edge contains `r (μ 2)`.

A finite proof of the sixteen possible side-membership patterns is a reasonable implementation of this parity argument. It is not an enumeration of host graphs or matchings.

For the cubic contradiction:

1. `SimpleGraph.sum_degrees_eq_twice_card_edges`, tightness, and the edge cap give
   \[
   m=12,\quad |V|=8,\quad \tau(G)=3.
   \]
   These are linear natural-number constraints suitable for `omega`.
2. Choose a square; the common lemma makes it chordless.
3. Delete its four vertices. Obtain four residual vertices, four residual edges, and \(\tau(H)=1\).
4. **Do not assert non-isolation from cubicity.** Instead, positive \(\tau(H)\) supplies an injective square in the four-vertex residual. Its map is bijective. Its four edges exhaust the residual edge set, so \(H\cong C_4\).
5. Cubicity gives precisely one cross neighbour per vertex on either square. Construct `μ` and prove `hcross`.
6. Apply the crossing lemma, then `tau4_le_card`, contradicting \(\tau(G)=3\).

Step 4 can alternatively use the positive-component induction argument, but the direct four-vertex argument is shorter.

## 5. Pitfalls and workarounds

| Pitfall | Workaround |
|---|---|
| Induced deletion silently replaced by incidence deletion | Public contracts use only `erase`; prove singleton transport once |
| Natural-number subtraction in edge counts | Use the additive `erase_edgeCount` identity |
| A component is proper but has the original edge count | Apply reductions to the original graph; remove whole \(C_4\) components |
| Cubic reduction requires the entire graph cubic | Use the checked local hypothesis on the four square vertices |
| Tight residual mistakenly assumed to have no isolates | Prove non-isolation separately; keep isolates in component sums |
| Cut endpoints substituted for cut edges | Use oriented `attachmentEdges`; derive endpoint distinctness only where justified |
| `Fintype` instance diamonds | Keep the original `[Fintype V]`; use the single named component instance; do not repeatedly install `Fintype.ofFinite V` |
| Arbitrary degrees fail to elaborate | Use `attribute [local instance] Classical.propDecidable` in structural sections |
| Classical instances obstruct finite computation | Keep certificate sections computational; do not wrap them in a classical instance override |
| `edgeCount` fails to reduce with `decide` | Rewrite using the existing `edgeCount_eq_card` bridge |
| `tau4` is noncomputable | Prove finite upper/lower certificates and apply the minimum semantics |
| `IsC4Map` lacks decidability | Add the checked instance; injectivity is decidable because its domain is `Fin 4` |
| Existential `decide` is expensive | Supply explicit witnesses, then check them |
| `↪g` used for a non-induced copy | Keep injective adjacency-preserving maps; graph embeddings are induced |
| Heterogeneous isomorphism confusion | `Nonempty (G ≃g H)` is valid across vertex types; use `.symm` deliberately |
| Equality induction quantifies only `W : Type` | Quantify `W : Type u`; residual subtypes stay in the same universe |
| Named residual isomorphism identifies only support | Prove coverage/non-isolation before constructing the whole-graph equivalence |
| Chorded-square strictness used at maximum degree four | Require the explicit subcubic hypothesis |
| Guessed Mathlib module paths | Components are in `Connectivity/Connected.lean`; paths are in `Paths.lean`, not a presumed `Walk/Path.lean` |
| Shared declaration accidentally defined twice | Move it atomically from interface to destination; retain only public imports at the boundary |
| Linter noise hides errors | Fix unused section variables locally; do not globally disable the standard linter set |
| “Proved” wrapper still depends on a hole | Audit the declaration’s transitive axioms |

The checked `compGraph_connected` declaration triggers an unused-section-variable warning for `[Fintype V]` in the interface harness. Its proof is valid. When distributing it, place it outside the finite section or use `omit [Fintype V] in`; no global linter suppression is needed.
